Time to Value by Level

Time to value (TTV) is implementation start to go-live, in months, for completed projects only. Go-lives pinned to Dec 31 are treated as placeholders and excluded. Remaining time is the estimated go-live minus today for active projects in the tier.

Active Projects vs. Peers

Estimated go-live is the start date plus the median TTV of the project's tier (or the whole portfolio when the tier has fewer than 5 completed projects). Projects already past that point use the tier's 75th percentile, with at least 2 months remaining. "Plan vs peers" is the planned duration minus the peer median; Aggressive means the plan is shorter than 75% of peers, Padded means longer than 75% of peers.

How Levels Are Assigned

Every project gets a label like Medium 2: a tier (Low / Medium / High) for overall size and complexity, and a level (1–3) for how many core modules were bought. Projects are only compared with others in the same group.

Level (1–3): core modules contracted

Core modules are Community Development, Business Management and Environmental Health. Level 1 = one core module, Level 2 = two, Level 3 = all three. If none is listed, Level 1 is assumed.

Tier (Low / Medium / High): size and complexity

Each factor below is scored 0 (small), 1 (medium) or 2 (large). The scores are averaged over the factors that have data. An average under 0.67 is Low, 0.67 to under 1.34 is Medium, and 1.34 or more is High.

The add-on score goes up one point for on-prem hosting and down one point for a Phase 2 add-on project. Client or city population is not used.
