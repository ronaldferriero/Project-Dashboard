Services Consumption by Project

Services value only (SaaS excluded), spread over a stage-weighted implementation curve rather than a straight line. Duration runs from the implementation start date to one month after go-live (assumed project close). The curve shape (12-month or 18-month) is chosen by whichever is closer to the project's actual duration, then scaled to that project's own length so longer or shorter projects still reach 100% at their own close date. A go-live pinned to Dec 31 is treated as a placeholder date, not a real one, so those projects are shown as fully consumed.
